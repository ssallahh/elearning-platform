# منصة التعلم الإلكتروني

منصة متكاملة للتعلم عن بعد وبيع الكورسات الرقمية.

## التقنيات المستخدمة
- Backend: Node.js, Express, PostgreSQL
- Frontend: React, Material-UI
- Mobile: Flutter
- Infrastructure: Terraform, AWS

## كيفية التشغيل
1. انسخ المستودع: `git clone <url>`
2. ثبّت dependencies للbackend: `cd backend && npm install`
3. ثبّت dependencies للfrontend: `cd frontend && npm install`
4. شغّل الخادم: `npm run dev`
5. شغّل الواجهة: `npm start`
